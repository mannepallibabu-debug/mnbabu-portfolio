# Portfolio Website

This is a professional, responsive, and modern portfolio website built as a static site. It is easy to host on Netlify, Vercel, GitHub Pages, or any basic web hosting service.

## Files

- `index.html` – main page structure
- `styles.css` – styling and responsive layout
- `script.js` – mobile menu, reveal animations, and form interaction

## Customize

Replace the placeholder content in `index.html` with your real:

- Name
- Title
- About text
- Skills
- Experience
- Projects
- Contact information
- Social links

## Hosting

You can host this site on any static hosting platform:

- Netlify
- Vercel
- GitHub Pages
- cPanel static hosting

### Upload instructions

1. Upload all project files to the hosting platform.
2. Point the site to the root folder containing `index.html`.
3. Your portfolio will be live immediately.

## Quick local preview

Open `index.html` directly in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
